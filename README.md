# Budget X

Консольное приложение для учёта личных финансов. Работает в терминале, не требует внешних зависимостей. 

## Возможности

- Доходы и расходы по категориям
- Бюджет по категориям с контролем лимитов (✅/🔴)
- Инвестиции: учёт вложений, доходность, обновление стоимости
- Подушка безопасности: цель, прогресс, пополнения
- Статистика с ASCII-графиками: по категориям, по месяцам, накопленный баланс
- Фильтры: по типу, месяцу, диапазону дат, тексту
- Редактирование и удаление транзакций
- Экспорт в CSV с BOM (`utf-8-sig`)

## Запуск

```bash
python3 main.py
```

Без сторонних библиотек — только стандартная библиотека Python.

## Структура

```
main.py           # точка входа, главное меню
config.py         # цвета, константы
storage.py        # загрузка и сохранение budget.json
transactions.py   # доходы, расходы, список, редактирование, удаление
categories.py     # управление категориями и лимитами
analytics.py      # статистика, графики, инвестиции, подушка
export.py         # экспорт в CSV
data/budget.json  # файл данных (в .gitignore)
exports/          # выгруженные CSV (в .gitignore)
```

## Формат данных

Все данные хранятся в `data/budget.json`:

- `categories` — списки категорий доходов и расходов
- `transactions` — массив операций (income / expense / saving)
- `investments` — вложено и текущая стоимость
- `safety_pillow` — цель и накопленная сумма
- `budgets` — месячные лимиты по категориям

## Управление

Главное меню:

```
[1] ➕ Доход                  [2] ➖ Расход
[3] 📋 Список                 [4] 💼 Инвестиции + Подушка
[5] 📊 Статистика             [6] 🏷️ Категории
[7] 💾 Выгрузить              [8] 🚪 Выход
```

В списке транзакций: ввод ID для редактирования, `у+ID` для удаления.
В статистике: выбор периода (текущий месяц, прошлый, всё время, свой диапазон).
В категориях: добавление, переименование, удаление, установка лимита (кнопка `л`).
